# invoi

## AI-Powered Invoice Management Dashboard

invoi is an intelligent invoice management platform that combines a modern web dashboard with AI-driven automation and analytics to streamline how invoices are tracked, processed, and reported.

## 📌 Overview

invoi helps businesses manage their invoicing workflow end-to-end — from data entry and validation to reporting and insights — with AI assistance reducing manual work and errors along the way.

## 🏗️ Project Structure

This repository is organized into independent modules, each with its own detailed README:

```text
invoi/
├── frontend/       → UI/dashboard (see frontend/README.md)
├── backend/        → API & business logic (see backend/README.md)
├── reports/        → Power BI reporting assets
└── README.md       → You are here
```

| Module | Description | Docs |
|---|---|---|
| Frontend | Dashboard UI, user experience, client-side logic | `frontend/README.md` |
| Backend | API, database, business logic, integrations | `backend/README.md` |
| Reporting | Power BI dashboards & analytics | — |

## ✨ Key Features

- AI-assisted invoice processing and data extraction
- Centralized invoice management dashboard
- Automated reporting and analytics (Power BI)
- Role-based access for team collaboration

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/JxTechStudio-org/invoi.git
cd invoi
```

### 2. Set up the backend

Follow the setup instructions in [backend/README.md](backend/README.md).

### 3. Set up the frontend

Follow the setup instructions in [frontend/README.md](frontend/README.md).

### 4. Configure environment variables

Configure the required `.env` files as documented in each module's README.

### 5. Run the project

Start the backend and frontend according to the instructions provided in their respective README files.
